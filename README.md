# Taller 4 — Riego Smart
## Patrones de Diseño: Observer + Factory

### 📋 Descripción
Sistema de gestión de alertas y productos para un sistema de riego inteligente en una finca agrícola. Implementa los patrones de diseño **Observer** para notificación de alertas y **Factory Method** para la creación de diferentes tipos de productos con cálculo automático de costos.
